# Project guidelines

- Read the root [README](README.md) and the README for the section you are editing.
- Use Markdown for text. Preserve existing paths and filenames unless the requested change calls for moving or renaming them.
- Use the [story bible](01-story-bible/README.md) to check established canon. Flag inconsistencies and record unresolved decisions in [Open Questions](OPEN_QUESTIONS.md).
- Keep edits within the requested scope. Add story content or revise the manuscript only when the author asks.
- Record significant project changes in the [changelog](CHANGELOG.md). Ask for the author's approval before committing or pushing.
