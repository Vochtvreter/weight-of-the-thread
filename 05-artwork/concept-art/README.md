# Concept art

Store full-resolution generated or drawn visual explorations here. Catalog each file and version in the [artwork index](../imported-artwork-index.md).

## Character concepts

Save each character’s full-resolution portrait and complete generation prompt here under their name, with the same version suffix on both files. The initial draft is `v01`, for example `ava/ava-concept-v01.png` and `ava/prompt-v01.md`. Keep both files for every version so the exact prompt stays available if the shared style evolves.

When a new draft becomes the current reference, update `portrait.png` and `prompt.md` together in that character’s folder under [Characters](../../02-characters/README.md). Use those stable filenames for the current pair and link the prompt to its versioned source. Update the navigator’s WebP and the [artwork index](../imported-artwork-index.md) to match.
